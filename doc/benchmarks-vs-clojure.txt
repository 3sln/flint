Clojure 1.12.1 on OpenJDK 25. Reproduce with `bin/bench-vs-clojure`.

The tight loop's Clojure number was checked for validity rather than trusted:
0.39 ms for 10^6 iterations is about one cycle each, which is what a folded-away
loop also looks like. It scales linearly -- 0.387 / 1.546 / 6.337 ms for 1, 4
and 16 million -- so the work is real. Clojure compiles a primitive loop/recur
to native code through the JIT, and that is simply a different class of thing
from an interpreter's dispatch loop.
